# Currency Converter Using API

## Project Overview
The Currency Converter is a web-based application developed using Java and an external exchange-rate API. It allows users to convert an amount from one currency to another using current available exchange-rate data.

## Technologies Used
- Java 23
- HTML
- CSS
- JavaScript
- Exchange Rate API
- VS Code
- HTTP Server

## Features
- Currency conversion
- Support for multiple currencies
- Real-time exchange-rate retrieval through an API
- Currency swap option
- Conversion history
- Clear history option
- Responsive user interface

## Supported Currencies
- INR – Indian Rupee
- USD – US Dollar
- EUR – Euro
- GBP – British Pound
- JPY – Japanese Yen
- AUD – Australian Dollar
- CAD – Canadian Dollar
- SGD – Singapore Dollar
- AED – UAE Dirham
- CHF – Swiss Franc
- CNY – Chinese Yuan
- NZD – New Zealand Dollar

## Project Files
- `CurrencyConverterServer.java` – Java backend server and API integration.
- `index.html` – Application interface.
- `style.css` – Application styling.

## How to Run

1. Install Java JDK 23.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java server:

```bash
javac CurrencyConverterServer.java
```

5. Start the server:

```bash
java CurrencyConverterServer
```

6. Open `index.html` using Live Server.

Backend server:

`http://localhost:8083`
